# Sistema de Gestión de Capítulos Estudiantiles

Este repositorio contiene una prueba de concepto y desarrollo inicial para un sistema de gestión enfocado en los capítulos estudiantiles del Instituto Tecnológico de Morelia. 

## Estado del Proyecto
Este es un proyecto académico en curso desarrollado para el Servicio Social. Actualmente se encuentra en una fase de transición: la versión inicial se construyó con tecnologías web tradicionales y ahora se está explorando una refactorización hacia componentes con React para mejorar la interfaz.

## Tecnologías / Stack
* Frontend: HTML5, CSS3, JavaScript (Vanilla).
* Frontend (En transición): React.
* Backend / Endpoints: PHP.

## Notas
El proyecto contiene funcionalidades básicas y demostrativas. Se utiliza como entorno de práctica para la implementación de endpoints y el aprendizaje de nuevos frameworks de frontend.
